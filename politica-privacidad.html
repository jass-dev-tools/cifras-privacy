2. Datos que recopilamos

La aplicación solicita únicamente el permiso de cámara. Este permiso se utiliza exclusivamente para funcionalidades relacionadas con el juego.

5. Conservación de los datos

Conservaremos tus datos mientras mantengas tu cuenta activa o durante el tiempo necesario para cumplir con obligaciones legales.

6. Seguridad

Aplicamos medidas técnicas y organizativas razonables para proteger tu información frente a accesos no autorizados, pérdida o alteración.

7. Derechos del usuario

Puedes solicitar el acceso, rectificación o eliminación de tus datos personales, así como retirar tu consentimiento cuando corresponda, escribiendo a darthplaguesi@gmail.com.

8. Cambios en esta política

Esta política puede actualizarse para reflejar cambios legales o funcionales de la aplicación. Se recomienda revisarla periódicamente.
